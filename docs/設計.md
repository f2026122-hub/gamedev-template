# 設計
-プレイヤー
-敵 ステージ1
-敵 ステージ2
- トランポリン
- スコアボード

オブジェクトが持っている情報
プレイヤー　　座標(x,y)、移動速度、残りHP、飛ぶ方向は上下、左右移動はできない、画面中央、スペースキーが押されているときだけ上昇する。
敵 ステージ1　座標(x,y)、プレイヤーの方向にビームを発射、発射する0から固定して予測線が表示される
敵 ステージ2　座標(x,y)、画面左右から10体の敵が横に流れていく
トランポリン　座標(x,y)
HUD          とんだ回数

プレイヤの速度 = 200
プレイヤーのHP = 1
クリアに必要なとんだ回数 = 50
敵 ステージ1が撃つビーム速度 = 100
敵 ステージ1が撃つビーム間隔 = 3秒

タイトル -->Enterキー-->プレイ中
プレイ中 -->HPが0 --> ゲームオーバー
ゲームオーバー --> Enterキー --> タイトル
プレイ中 --> とんだ回数が25 --> 敵が変わる、ステージが変わる
プレイ中 --> とんだ回数が50 --> ゲームクリア
ゲームクリア --> Enterキー --> タイトル
