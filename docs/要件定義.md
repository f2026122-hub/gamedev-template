 # トランポリンゲーム 要件定義

## 1. ゲーム概要

トランポリンで跳びながら敵を避け、規定回数のジャンプを達成するゲーム。

## 2. 操作

- スペースキーを押すと、プレイヤーがジャンプする。
- ジャンプするたびに、ジャンプ回数を1回増やす。

## 3. 勝利条件

- 敵に一度も接触せず、ジャンプ回数が50回に到達する。
- 条件を満たすとクリア画面を表示する。

## 4. 敗北条件

- プレイヤーが敵に接触する。
- 接触するとゲームオーバー画面を表示する。

## 5. 完成条件

- スペースキーでプレイヤーがジャンプできる。
- ジャンプするたびにジャンプ回数が1回増える。
- ジャンプ回数が50回になるとクリア画面が表示される。
- 敵に接触するとゲームオーバー画面が表示される。
- 25回とぶとステージが変わり敵も変わる
- ステージ2へ変わるとき画面がホワイトアウトする

## 6. 作成しないもの

- 敵への攻撃機能
- 3つ目以降のステージ
- パワーアップアイテム
